# Архитектура

В данном документе будет описана архитектура проекта.

## Планируется

- микросервисная архитектура;
- взаимодействие сервисов по HTTP и через Apache Kafka;
- отдельные базы данных или схемы для сервисов (при необходимости);
- кэширование с использованием Redis;
- контейнеризация с помощью Docker и Docker Compose.

> Документ будет дополняться по мере проектирования системы.
